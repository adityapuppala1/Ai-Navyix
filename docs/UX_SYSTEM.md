# Navyix UX and visual direction
Premium, calm industrial intelligence: navy graphite surfaces, bright mint and restrained cobalt accents, soft elevated layers, Space Grotesk headings and readable DM Sans/system body. Consistent status words and visible provenance matter more than ornamental charts.
## Screens
Organization onboarding/invites, Projects, My work, Requirements, Design, Builds/Tests, Readiness, Issues, Review Inbox, AI source approval, Integrations, Members, Usage, Settings, Audit.
## Key workflow
Project and artifact selector stays visible -> readiness outcome -> mandatory blockers with owner -> filterable criterion list -> evidence drawer with exact test/build/environment -> propose action -> fresh evidence -> reassess and immutable history. Distinguish AI drafts from executed checks.
## Component system
Responsive shell, sidebar/drawer, breadcrumb, search/command, tabs, sortable accessible tables, evidence timeline, revision diffs, status chips with labels, confirmation and error dialogs, progress/cancel states, empty/skeleton/partial/offline conditions, notifications and AI suggestion diff accept/edit/reject.
## Motion/3D
Three.js/React Three Fiber for optional hero and meaningful dependency visuals; progressive WebGL enhancement with CSS/SVG fallback. Honor reduced motion, slower devices, keyboard and touch. Do not use WebGL for tables or forms. Motion reflects interaction hierarchy; never communicates readiness through animation alone.
## Quality
Mobile 320px+, touch tablet, laptop, ultrawide. Target WCAG 2.2 AA, color contrast, focus, 200% zoom, text equivalents, screen-reader and keyboard tests. Validate Chrome, Edge, Firefox, Safari, iOS Safari and Android Chrome. Set realistic performance budgets and profile on devices.
